# 分类售后规则（2026-10-21）

## 依据及适用范围

核对日期为 2026-10-21。本项目演示中国大陆网络零售售后申请的预审和确认，不代表已经退款，也不完整实现任一平台的全部规则。

- [消费者权益保护法](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_615af9ed6bcd4974bf853dd2e02bc663.html)：第24条区分质量救济与无理由退货，第25条规定无理由退货及例外。
- [网络购买商品七日无理由退货暂行办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_26ca8fe29e184edd899fa0a7a060d935.html)：第6—9条涉及例外和完好性，第10条规定期限起算，第20条涉及显著标注和确认。
- [消费者权益保护法实施条例](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)：第12、18、19条涉及承诺、期限及不得扩大例外。合理拆包查验不能一概认定为不完好。
- [京东自营售后总则](https://help.jd.com/user/issue/126-406.html)将退货与换货期限分别说明；[第三方卖家总则](https://help.jd.com/user/issue/329-4274.html)也区分质量、物流损、个人原因。平台类别和店铺承诺有差异，不能拼成所有商品统一的“15天退货”。

## 已实现的决策

| 输入情况 | 处理 |
|---|---|
| 普通商品、事实齐全、商品完好或仅合理查验 | 无理由窗口至少7天；可信记录中的更长商家承诺生效 |
| 鲜活易腐、定制、已交付报刊、已下载/拆封数字商品 | 不自动进入普通无理由流程；有明确标注和购买确认时限制个人原因申请，其他售后请求仍可核实 |
| 拆封健康类、激活后贬值类、已明示特价瑕疵/临期类 | 结合拆封/激活事实及购买确认；确认记录缺失转人工，不直接拒绝 |
| 商品或政策事实缺失 | 请求补充并人工核实，不默认普通商品，也不据此直接拒绝全部售后 |
| 质量问题、描述不符、物流损或其他待核实原因 | 进入人工证据核实，不以7/15天一刀切，也不自动判为已核实 |
| 无理由窗口已过 | 个人原因不自动通过；质量等其他权利继续按具体依据核实 |

`REASON_REQUIRED/can_apply=true` 表示可补充原因申请核实，不能解释为已经批准退货。质量类最终是否退货、更换或维修，需要合同、具体三包规则及证据，项目当前只提供人工核实入口。

## 数据与执行边界

`order_return_policies` 保存订单关联的类别、商品状态、购买确认、拆封/激活事实、无理由承诺和政策版本。通过 V4 Flyway 增量迁移创建，未知历史订单不自动套用样例政策。内存演示由独立样例仓库提供事实；PG 缺失记录不回退演示数据。

事实来源必须是受信业务记录。现有 HTTP 工具不能写这些字段，模型和PDF不能通过提供“商品类别/支持退货”覆盖业务值。若将来增加管理员维护接口，需要独立鉴权和审计。

草稿保存政策指纹；类别、状态、商家承诺或版本变化会使未完成的旧确认失效，需刷新草稿并重新确认。已提交申请重试仍返回原回执。仅日期跨过无理由截止时刻，不会重置已经及时创建的草稿，其一小时有效期仍受限。

明确提交了质量问题并进入人工核实后，即使订单原本处于无理由期限内，也不能通过直接确认绕过核实。

演示订单：O-7101普通键盘；O-7201鲜活香蕉；O-7202定制水杯，归属U-1001。PG签收日期首次插入后持久保留，不随重启刷新。

尚未覆盖：精确小时级生鲜时效、多件/组合订单的部分退款、全部品类三包、举证争议和人工审核台。质量问题提交核实不意味着承诺一定退货。冻结的历史评测集维持原口径，不作为本轮政策验证数据。
