# 单订单查询与缺失结果修复（2026-10-22）

用户报告“查询订单101”出现模型失败。只读原任务错误类型确认为LocalModelTruncatedError，说明查询尚未完成，不能把此错误解释为查库后不存在。

当前Java客户端契约为O-加四位数字。因此101必须提示提供完整编号，不能自动补成O-0101，也不能未经查询就声称不存在。

## 修改

- 明确的单订单查询先识别完整输入；编号格式不符直接返回正常澄清，不调用模型或业务接口。
- live模式的完整单订单查询通过现有受控工具调用Java，结果由程序依据校验后的事实组装，无需两次模型生成。鉴权与订单归属仍由Java执行。
- 业务404显示“未找到你可访问的订单”，不泄露是否属于别人；500、超时及异常返回仍是服务故障，不能伪装成不存在，也不显示成模型故障。
- 用户明确提供不完整编号时，历史追问不得替换为上一笔订单；复合政策、多订单和退货申请不使用此只读快捷路径，确认边界不变。
