# 本机门户安全与恢复修复（2026-10-21）

## 修改

- PostgreSQL、Redis 与 Java 宿主机映射绑定 127.0.0.1。API 原本已为本机绑定。
  Redis 仍未启用密码；该配置只适用于可信本机演示，不是公网部署或多租户隔离。
- 图片任务超过 15 分钟后，可以通过原任务同步入口终止并释放会话锁。
  在 PostgreSQL 事务内重新校验归属、任务状态、超时与活动任务编号；
  不重放模型调用，不终止业务 Agent，不推断退款结果。
- 已终止图片任务的迟到回包不能覆盖失败状态，或释放另一项新任务的锁。
- 部署验收按稳定业务用户 ID 查找用户名，支持预置账号改名。
  账号及密码仅保留在本机忽略文件，不进入此报告。

## 验证

- 登录、鉴权、恢复入口及验收账号选择：38 项离线定向测试通过。
- PostgreSQL 独立随机 schema：10 项通过，包含超时、跨用户拒绝、
  活动任务不匹配、业务任务拒绝恢复及迟到结果不覆盖新任务锁。
- 本轮不调用真实模型；这些结果不代表模型识图质量或全面安全审计。
- 前端 Node 测试 5 项通过，图片执行中提供同步按钮且不提供业务确认权限。
- 已重新创建四个容器，全部健康；四个宿主机端口均为 127.0.0.1 绑定，
  PostgreSQL、Redis 与模型缓存沿用原持久卷。
- 部署 HTTP 验收 27 项通过，覆盖改名登录、身份隔离、近期任务拒绝终止、
  超时图片恢复与解锁、用户确认前零写入、重复确认只产生一次业务写入。
- Windows 本机 localhost 优先尝试 IPv6 导致验收连接等待；
  脚本对 localhost 明确使用已绑定的 IPv4，并设置5秒连接超时。
  显式 IPv6 与其他数据库主机不改写。
- 常规构建未命中依赖缓存，下载约1.8MB的pip后停止；
  比较本地与旧应用镜像 requirements.txt 的 SHA-256 一致后，
  改为从旧镜像复制应用代码的无网络构建，未继续下载项目依赖。
  回退镜像保留为 opspilot-api:before-portal-bugfix-20261021。
- 本机模拟验收只清理本轮随机标识的虚构会话、订单和申请；
  不清空数据卷、不修改已有业务记录、不外发图片。
